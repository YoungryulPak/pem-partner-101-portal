4.3 Unified dashboard

Time 20 minutesAWS cost NoneNeeds 4.2 completedSource script Technical_Exercise/phase4_ai_cnapp_incident/dashboard/build_dashboard.py

Goal

Combine the results of several tools into one list, ranked by severity, in one page.

Why it matters

The biggest value of a security platform is one view of many sources. Each tool has its own format, scale and screen. Normalizing all of them into one model lets you answer "what do I fix first" in one place. This is also the job of the governance layer in PEM. It gives a single risk view across every tool. See Governance and orchestration.

Before you start

You have Prowler's JSON (OCSF) output and Kubescape's JSON report from 4.2 Open-source CNAPP: Prowler and Kubescape. The Prowler file name contains the account ID and a timestamp, so look it up:

ls phase4_ai_cnapp_incident/oss_cnapp/prowler_results/

Steps

Step 1: build the dashboard

cd phase4_ai_cnapp_incident/dashboard
python3 build_dashboard.py \
  --prowler-json ../oss_cnapp/prowler_results/<PROWLER_OUTPUT>.ocsf.json \
  --kubescape-json ../oss_cnapp/kubescape_results/nsa-report.json \
  --output dashboard.html
PartMeaning
--prowler-jsonProwler results in OCSF JSON
--kubescape-jsonKubescape's NSA framework report
--outputThe HTML file to write

The script keeps only failed items, sorts them by severity and tags the ones that match the known lab weaknesses.

Step 2: open it

open dashboard.html

(xdg-open on Linux.)

Expected: coloured severity groups with summary counts. The console output lists matches for the public bucket, the open SSH port and the cluster-admin binding.

Step 3 (optional): tune a rule

If "over-broad IAM permissions" is not matched, adjust the keywords in KNOWN_LAB_VULN_KEYWORDS in the script so they fit Prowler's real wording. Tuning detection rules to a real environment is itself part of the work.

Verify

The three known weaknesses are matched, and severities are colour-coded.

Multi-cloud

This lab merges two sources from one cloud account. In a multi-cloud setup you would add the Azure and Google Cloud scan results to the same model.

Troubleshooting

SymptomLikely causeFix
File not foundThe Prowler file name differsUse the name from ls
No matchesKeyword text differsSee Step 3

Clean up

Delete dashboard.html if you share the folder.

Check yourself

  1. Why does normalizing results matter?
  2. What is lost when severities from two tools are merged?
