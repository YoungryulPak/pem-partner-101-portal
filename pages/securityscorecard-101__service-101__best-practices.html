Best practices

Users and access

  • Predefined roles: Org Admin (full), Editor (manage data, no settings), Viewer (read only). Admins cannot change their own role.
  • Invitations expire after 10 days. Use SCIM if the customer provisions users that way.

Vendors and intake

  • In September 2026 the platform gained a new vendor intake form. Business stakeholders can use it with no account. It calculates an inherent risk tier. It fills the vendor record in All Companies.
  • Use Vendor Intake whenever a review or sign-off is needed before a vendor is added. Direct add and CSV import skip approval.
  • Add and monitor uses a vendor slot. Add without monitoring works even with no slots left, and monitoring can be turned on later.
  • Order risk-level rules from specific to general: the first matching rule wins. Use the dry run before publishing.
  • Add custom vendor fields and tags early, so vendors are easy to find and filter.

Assessments

  • Start from a built-in template (CAIQ Lite, SIG Lite) or auto-import the customer's spreadsheet or document.
  • Use AI evaluations so reviewers only look at flagged answers. The evaluation types are a policy check, document extraction, and an evidence check.
  • Each vendor gets its own copy of the questionnaire, locked once sent.

Monitoring

  • Start with curated presets, then save the customer's own filters.
  • Choose the action by urgency. Flag makes it visible with no notification. Request remediation sends a formal email. Accept risk records the risk without an email. Internal request notifies your own team.
  • A rescan checks a vendor's "fixed" status. If the finding is still there, it reopens.

Workflows

  • Every workflow needs a trigger and an End block. Fix all errors. Warnings can be saved, but they are worth reading.
  • Give each Decision Switch a catch-all branch.
  • Always dry run, then publish with an owner and an alert.
  • AI blocks only advise. Connect their answers to an action, such as sending an email.

Own company side

  • Fill the knowledge base from completed questionnaires, documents and compliance tools. If content is thin, the assistant says so instead of guessing.
